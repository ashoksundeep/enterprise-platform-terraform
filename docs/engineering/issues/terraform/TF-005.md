# TF-005 — Azure Provider Registration Conflict

## Sprint

Sprint 2

## Component

AzureRM Provider

## Problem

Terraform plan failed.

## Error

409 Conflict

Resource Provider Registration

## Investigation

Reviewed AzureRM provider behavior.

## Root Cause

Azure was already registering providers.

Terraform attempted concurrent registration.

## Resolution

Retried after registration completed.

Documented provider registration behavior.

## Validation

terraform plan

## Lessons Learned

Azure provider registration is asynchronous.

Terraform may fail temporarily.
