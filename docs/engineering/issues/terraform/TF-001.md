# TF-001 — Invalid Terraform Block Syntax

## Sprint
Sprint 2

## Component
Terraform Module

## Problem

Terraform failed during formatting.

## Error

terraform (

An argument or block definition is required.

## Investigation

Reviewed versions.tf.

Found:

terraform (

instead of

terraform {

## Root Cause

Incorrect Terraform block syntax.

## Resolution

Changed:

terraform (

to

terraform {

## Validation

terraform fmt

terraform validate

## Lessons Learned

Terraform blocks use curly braces, not parentheses.

## Interview Talking Point

A small syntax error prevented Terraform from parsing the module. I reviewed the parser error, corrected the block syntax, and validated the module.
