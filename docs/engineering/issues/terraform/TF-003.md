# TF-003 — Unsupported Module Arguments

## Sprint

Sprint 2

## Component

Reusable Azure Network Module

## Problem

Terraform reported unsupported arguments.

## Error

Unsupported argument

aks_subnet_name

## Investigation

Reviewed variables.tf.

Compared live configuration with module interface.

## Root Cause

Module variables were not declared.

## Resolution

Added missing variable declarations.

## Validation

terraform validate

## Lessons Learned

Reusable modules must explicitly expose every accepted variable.

## Interview Talking Point

Terraform validates module interfaces before planning infrastructure.
