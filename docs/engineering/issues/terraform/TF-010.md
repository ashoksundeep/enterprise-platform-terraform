# TF-010 — Azure Container Registry Premium Feature Restriction

## Sprint

Sprint 3

## Problem

Terraform apply failed.

## Error

public_network_access_enabled can only be disabled for a Premium SKU

## Investigation

Reviewed:

Terraform variables

Terraform provider schema

AzureRM documentation

Terraform plan

Azure API response

## Root Cause

Terraform generated a valid plan.

Azure rejected the request because the Standard SKU does not support disabling public network access.

## Resolution

Development

Standard SKU

Public Network Enabled

Production

Premium SKU

Public Network Disabled

Private Endpoint

## Validation

terraform apply

az acr show

## Lessons Learned

Terraform validation and Azure service validation are different.

## Interview Talking Point

This issue demonstrated the difference between infrastructure-as-code validation and cloud provider runtime validation.
