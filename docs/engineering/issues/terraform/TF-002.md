# TF-002 — Incorrect Module Source Path

## Sprint

Sprint 2

## Component

Live Environment

## Problem

Terraform could not locate the reusable module.

## Error

Unreadable module directory

## Investigation

Verified directory structure.

Compared current path with repository tree.

## Root Cause

Incorrect relative module path.

## Resolution

Updated module source to the correct relative path.

## Validation

terraform init

## Lessons Learned

Always verify module paths after restructuring repositories.

## Interview Talking Point

Terraform module resolution depends entirely on directory layout. Repository refactoring requires updating all module source paths.
