# LNX-003 — PATH Not Updated After pipx Installation

## Sprint

Sprint 2

## Problem

pre-commit command not found.

## Root Cause

~/.local/bin was missing from PATH.

## Resolution

Added

export PATH="$HOME/.local/bin:$PATH"

to ~/.bashrc.

## Validation

which pre-commit

pre-commit --version

## Lessons Learned

Installing tools is not sufficient; ensure their binary directory is on PATH.
